# uTempGuard v0.5.0 — публичная загрузка и документация

## Главное

- **Готовый ZIP для Windows** `uTempGuard-v0.5.0-win.zip`: скачиваемый пакет с рабочими скриптами, 28 SVG/температурными иконками, двумя локализациями и понятными точками входа. **Не является EXE**, не подписан отдельным сертификатом uTempGuard.
- `uTempGuard-v0.5.0-win.zip.sha256` — SHA-256 для проверки скачанного файла.
- **Первоначальная установка через `00_START-HERE.cmd`**: подписанная FinalWire AIDA64, безопасная Observe-конфигурация, дополнительное слово INSTALL для запуска/автозагрузки. Существующий `config.json` никогда не перезаписывается.
- **GitHub-проект оформлен:** компактная русская презентация как главный README, зеркальная английская версия, читабельные кнопки скачивания/документации, описание возможностей, предупреждения, скриншоты разработки.
- Подробные **INSTALL и USER_GUIDE** на RU/EN, карта файлов и правила обновления без удаления данных.
- Полное историческое README сохранено в `docs/ARCHIVE_README_2026-10-25.md`. Никакие исходные скрипты или датчики не переносились — это может нарушить автозапуск на существующем ПК.
- Два пользовательских CorelDRAW CDR в `assets/logo/` **не удалены** и теперь игнорируются Git. В ZIP они не включаются.
- ZIP собирается по белому списку: без `.git`, тестов, секретов, `config.json`, Live-разрешений, локальных журналов, персональных фотографий и CDR.

## Установка

1. Скачать **прикреплённый ZIP** ниже — не «Source code ZIP» GitHub.
2. Полностью извлечь архив в постоянную папку `C:\Tools\uTempGuard`.
3. Открыть `00_START-HERE.cmd`, указать путь к **своей установленной** AIDA64 Extreme, включить реестровый экспорт SensorValues в AIDA64.
4. После явного подтверждения `INSTALL` запускается наблюдение. Аварийное выключение **по умолчанию запрещено**.

[Инструкция RU](https://github.com/sunpole/uTempGuard/blob/main/docs/INSTALL_RU.md) · [Install EN](https://github.com/sunpole/uTempGuard/blob/main/docs/INSTALL_EN.md) · [Руководство RU](https://github.com/sunpole/uTempGuard/blob/main/docs/USER_GUIDE_RU.md) · [English guide](https://github.com/sunpole/uTempGuard/blob/main/docs/USER_GUIDE_EN.md)

**Внимание:** ZIP не содержит Git-историю и поэтому не обновляется Git Updater автоматически. Для безопасных автоматических обновлений нужен клон репозитория. Старые локальные `config.json` и разрешения нельзя перезаписывать или удалять. Новая установка никогда не активирует Live или выключение сама.

**Тепловая защита не гарантирована:** компьютер может зависнуть или потерять данные. Пороги 70/75°C не универсальны для всех компонентов; не пытайтесь проверять их нагреванием ПК.
