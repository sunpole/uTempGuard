# uTempGuard v0.3.0 — новый интерфейс и официальный логотип

Windows 10 / Windows PowerShell 5.1 — исходный код и встроенный обновлятор.

- Новое тёмное меню у значка Windows вместо стандартного старого контекстного меню (WinForms, скруглённые углы, логичные разделы).
- Официальный логотип пользователя assets/u_logo_tempg2.svg, растровый ресурс WinForms и иконка в трее. Альтернативный логотип из эскиза не используется.
- Два независимых раздела «Показывать что» и «Выключать ПК по температуре», пять режимов с чекбоксами.
- Страницы температуры, ядер CPU, настроек положения/непрозрачности/вида/размера шрифта/фона, «О программе».
- GitHub, релизы, документация, проверка обновлений и ручной запуск Updater. Updater проверяет Git, требует UPDATE перед установкой.
- Бренд-кнопки в README. Прежнее стандартное меню остаётся как резервное на случай ошибки нового.

## Сохранение защиты

Не меняются config.json, live-approval.json, локальные настройки профиля, требования достоверности AIDA64, пороги 70/75 °C и права принудительного выключения. Изменение датчиков для аварийного отключения как и прежде требует отдельного подтверждения.

## Проверка и установка

Синтетические тесты и создание интерфейса без показа окна прошли на Windows PowerShell 5.1. Реальный UX на Windows 10 требует проверки пользователя. Браузер/библиотеки WebView2 не нужны.

Из локальной папки 015_uTempGuard:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Update-uTempGuard.ps1 -Action Apply

Введите UPDATE, если Updater предложит проверить и установить fast-forward main. После проверки:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Emergency-Control.ps1 -Action Status

При активном Live выключение по подтверждённым 75 °C может приводить к потере несохранённых данных, гарантия 100% при отказе Windows/датчиков невозможна. Не разогревайте специально CPU для тестов.
