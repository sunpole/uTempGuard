# uTempGuard v0.4.0 — компактное меню и RU/EN

На основе реальных снимков Windows 10 интерфейс стал компактным, адаптивным и двуязычным.

- Пункты меню — **26 px**, в одну строку вместо 45–68 px; короткие понятные названия и подсказки для средств доступности.
- Главное окно автоматически подбирает высоту по размеру рабочего стола. На обычном экране прокрутки нет; на очень низком она остаётся резервом, а длинный список датчиков разбит на **12 на страницу**.
- Сохранён официальный SVG-логотип пользователя, тёмное оформление и все функции мониторинга.
- Появилась страница **Язык / Language**: русский и английский, переключение без перезапуска, персональное сохранение настройки в LocalAppData.
- Пакет локализации: i18n/ru-RU.json, i18n/en-US.json, src/Guard.Localization.psm1 и docs/LOCALIZATION.md. Новые языки добавляются отдельными JSON без пересборки Windows-приложения.
- Реализована локализация основных экранов и уведомлений. Часть старых CLI-сообщений и резервного меню остаётся исходной (подробности в docs/LOCALIZATION.md).

**Безопасность:** параметры 70/75°C, режим Live, проверка AIDA64, допуски выключения, локальные config и настройки не изменяются. Если статус показывает ForcedShutdownArmed=False, аварийное выключение сейчас НЕ разрешено. Выбор языка его не включит.

Windows PowerShell 5.1 CI проверяет реальные контролы UI (без показа окна и силовых действий), ширину/высоту, RU/EN, целостность каталогов и основные защитные регрессии.

**Для пользователя с сохранёнными в Git снимками:** локальный коммит 9379673 с docs/screenshots/Screenshot_7.jpg и Screenshot_8.jpg пока не опубликован, так как git push origin main был отклонён: remote main уже содержал новые изменения.
