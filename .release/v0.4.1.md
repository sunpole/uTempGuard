# uTempGuard v0.4.1 — исправления меню, галерея SVG и безопасный Updater

- Исправлено перекрытие первой строки под шапкой: верхняя панель, содержимое и нижняя область используют отдельные строки Windows Forms TableLayoutPanel.
- Кнопка «Назад» теперь в фиксированной шапке всех вложенных страниц и доступна независимо от прокрутки. Esc возвращает на родительский экран, на главной странице закрывает меню.
- Раздел «О программе» больше не выглядит как набор ложных кнопок: информационные пункты — текстовые метки, официальный SVG — настоящая ссылка.
- Добавлена **оффлайн-галерея всех 28 оригинальных SVG** (docs/icon-gallery.html): тёмная/светлая панель, 32/64/128 px, диапазоны температур, демонстрация чередования _active каждые 0.4 секунды. Открывается из пунктов «Внешний вид» или «О программе», не меняет реальные температуры.
- Updater теперь различает отслеживаемые и неотслеживаемые изменения: незакоммиченные правки отслеживаемых файлов блокируют Apply; независимые незарегистрированные файлы остаются и не мешают; конфликт с новым файлом из GitHub блокируется ДО остановки монитора. Нет автоматического stash, reset или удаления файлов. Применение обновления по-прежнему требует ввода UPDATE.
- Изолированные тесты в Windows PowerShell 5.1 проверяют интерфейс/навигацию, набор всех SVG и три сценария Updater через синтетический git.exe.

**Защита:** никакие параметры Live, AIDA64, выбор датчиков, пороги 70/75°C или подтверждение принудительного выключения не меняются. По последнему предоставленному пользователем Status монитор работал в Live с разрешением ShutdownSensorMode=All. Этот набор включает GPU, накопители и другие экспортируемые AIDA64 каналы; значения 75°C для всех компонентов могут быть неуместны — проверьте выбор и подтверждение перед серьёзной нагрузкой.

При первой установке этой версии из старой программы, которая не обновлялась из-за локальных файлов, остановите монитор, вручную выполните git pull --ff-only origin main (если нет незакоммиченных отслеживаемых изменений), потом запустите монитор. В новой версии кнопка «Установить» работает через штатный Updater.

Документация и файлы: https://github.com/sunpole/uTempGuard
