# uTempGuard v0.5.1 — большое окно по двойному щелчку + 28 SVG прямо на GitHub

**Новое главное окно Windows:** теперь двойной щелчок по значку возле часов или по `00_START-HERE.cmd` / `Open-uTempGuard.cmd` открывает полноразмерную панель мониторинга, визуально основанную на промо-концепте: официальный логотип, крупная достоверная температура, число проверенных CPU-датчиков, состояние мониторинга, отдельный статус аварийного допуска и рабочие кнопки перехода к существующим настройкам, выбору языка, галерее, обновлениям. Это **реальная Windows PowerShell 5.1 / WinForms форма**, не макет-снимок и не HTML. Фактический вид отличается от ранее нарисованных концептов.

**Важное поведение:** правая кнопка возле часов всё так же открывает компактное меню. Закрытие большого окна скрывает панель, но **не останавливает** фоновый монитор и AIDA64. При входе Windows основное окно не открывается самопроизвольно — запуск остаётся фоновым.

**Просмотр изображений на GitHub:** добавлены настоящие каталог-страницы `docs/ICON_CATALOG.md` / `docs/ICON_CATALOG_EN.md`. GitHub прямо отображает все **28 SVG** (22 обычных и 6 предупреждающих) по двум темам и диапазонам. Под каждым изображением — ссылка на конкретный оригинальный SVG, который можно исправить в CorelDRAW. Это устраняет ограничение просмотра HTML-файла в браузере репозитория. Интерактивная локальная HTML-галерея с симуляцией 400 мс остаётся.

**Сборка:** `uTempGuard-v0.5.1-win.zip` + SHA256. Включены `Open-uTempGuard.cmd`, `Open-uTempGuard.ps1`, новый dashboard UI, Markdown-каталоги, обе локализации и 28 исходных векторных файлов. ZIP не включает AIDA64, личные `.cdr`, действующие `config.json`, `live-approval.json`, логи, тесты или Git историю.

**Проверки:** Windows PowerShell 5.1 CI проверяет сборку интерфейса из синтетических показаний и переход в «Нет достоверных данных», недопустимость ложного состояния Live, переводы RU/EN, 28 картинок и целостность ZIP. Живые датчики и реальное выключение в CI не запускаются.

**Безопасность:** прежняя конфигурация пользователя и допуски не меняются. Обновление не включает/не выключает аварийную защиту. При уже действующем Live на 75°C Windows по-прежнему может выключиться с потерей несохранённых данных. Проверяйте `Emergency-Control.ps1 -Action Status`; не нагревайте компьютер специально ради тестирования UI.
