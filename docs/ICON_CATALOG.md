### Как исправить неправильную иконку

1. Найди диапазон и тему в таблице.
2. Открой указанную SVG и соответствующий файл в `assets/logo/` в CorelDRAW.
3. Сохрани исправленный **SVG с прежним именем** и отправь изменение в GitHub. Не изменяй исходный CDR без собственной резервной копии.
4. После успешной сборки GitHub Actions обнови Git-клон программы. Для проверки, как это выглядит в реальном трее, используй масштаб **32 px** в локальной `docs/icon-gallery.html`.

**Важно:** сама галерея не считывает AIDA64, не нагревает процессор и не включает выключение. Правила отображения: [TRAY_ICONS.md](TRAY_ICONS.md).

*Всего на странице 22 обычных + 6 предупреждающих = 28 исходных SVG.*
