# Структура uTempGuard / Repository layout

## Важный принцип

**Исходная папка Git-клона не переорганизуется перемещением рабочих скриптов.** В проекте используется `$PSScriptRoot` и относительные пути, а автозапуск Windows указывает на конкретную папку. Перемещение без отдельной миграции может сломать запуск и проверки. В рамках этого релиза **ничего не удаляется и автоматически не переносится**: новые материалы организованы по назначению, старые файлы остаются в истории и в исходном дереве.

**Чистота для конечного пользователя** достигается отдельным ZIP с ограниченным набором файлов: исходный GitHub-репозиторий — место разработки, ZIP — готовая папка приложения.

## GitHub (разработка)

```text
uTempGuard/
├── 00_START-HERE.cmd       главное меню / первое знакомство
├── Install-uTempGuard.cmd  мастер установки
├── Start-uTempGuard.cmd    быстрый запуск
├── Open-Icon-Gallery.cmd   безопасная галерея
├── README.md               презентация RU, основной язык
├── README_EN.md            презентация EN
├── config.example.json     безопасный Observe-only шаблон
├── Setup-uTempGuard.ps1    первая установка
├── *.ps1, *.cmd, Launch.vbs  совместимые точки входа; НЕ переносить
├── src/                    движок, WinForms, датчики, переводы, трей
├── assets/
│   ├── logo/               оригинальные векторные SVG
│   ├── tray-icons/         подготовленные PNG 64 px (base64)
│   └── buttons/            элементы оформления GitHub
├── i18n/                   RU/EN JSON-словари
├── docs/                   руководства, галерея, история
│   └── screenshots/        сохранённые исторические изображения
├── tools/                  сборка и проверка ZIP, SVG rasterizer
├── tests/                  тесты с имитациями
├── .github/workflows/      проверки и публикация
└── .release/               заметки релизов
```

Глубокую историю инженерных решений сохраняет `docs/HANDOFF.md`. Предыдущий подробный README сохранён как `docs/ARCHIVE_README_2026-10-25.md`, чтобы он не потерялся после обновления главной страницы.

## Скачиваемый ZIP

Пакет содержит только текущие необходимые entrypoint-скрипты, безопасный шаблон, `src/`, `assets/`, `i18n/`, выбранные пользовательские документы и галерею. В ZIP **нет** папок `.git`, `tests`, `.github`, `.release`, `tools`, журналов, личных снимков, CDR, конфигурации Live, `config.json` и `live-approval.json`.

Распакованная папка `uTempGuard` имеет четыре понятных пользовательских .cmd вверху. Для штатной работы файлы скриптов внутри оставлены по исходным путям, потому что утилита и установщик используют `$PSScriptRoot`.

## Локальные рабочие CDR

Пользователь сообщил два локальных файла:

- `assets/logo/utg_wb_000.cdr`
- `assets/logo/Резервная_копия_utg_wb_000.cdr`

Это **рабочие оригиналы CorelDRAW**. Они остаются в текущем каталоге ПК, не включаются в общий ZIP и не загружаются на GitHub автоматически. Для аккуратного локального вида можно создать отдельный архив/резервную папку только после явного просмотра и подтверждения владельца. До тех пор **ничего не трогать**. Статус Git показывает их как `untracked`; новый Updater не удаляет их.

## Локальные данные

- `config.json`, `live-approval.json`: рядом со скриптами, игнорируются Git.
- `%LOCALAPPDATA%\uTempGuard`: статус, логи, визуальные параметры, выбор языка, дополнительные разрешения.
- Ярлык автозапуска содержит абсолютный путь к `Launch.vbs`, поэтому перенос установленной папки требует ручной переустановки ярлыка.

## Правила поддержки

1. Не менять относительные пути работающего монитора ради косметической сортировки папок.
2. Сохранять рабочие CDR и личные данные вне публичного пакета; не удалять без согласия.
3. Собирать ZIP из **явного белого списка** файлов, а не весь Git checkout.
4. Проверять содержимое ZIP и SHA-256 перед публикацией релиза.
5. При изменениях интерфейса сохранять официальный SVG пользователя; новый логотип не подменять.
6. Сохранять русскую документацию основной, английскую синхронизировать.
7. Не включать Live/ForcedShutdown при упаковке и установке.


## v0.5.1 — два оконных режима без переноса рабочих файлов

- `src/Guard.Dashboard.ps1` — полноразмерная WinForms-панель с уже проверенными температурными данными, датчиками и отдельным статусом Live-допуска; не содержит команд shutdown и не меняет исходный монитор.
- `Open-uTempGuard.ps1` — посылает текущему мониторному процессу однократный безопасный запрос только на **показ окна** (`%LOCALAPPDATA%\uTempGuard\dashboard.request`); при необходимости вызывает обычный `Manage.ps1 -Action Start`.
- `Open-uTempGuard.vbs` — запускает тот же запрос без лишнего окна консоли (через доверенный PowerShell Windows), `Open-uTempGuard.cmd`, `Start-uTempGuard.cmd`, `00_START-HERE.cmd` — пользовательские точки входа.
- `Launch.vbs` **не менялся**: автозапуск при входе в Windows остаётся фоновым и не показывает большое окно принудительно.
- `docs/ICON_CATALOG.md` и `docs/ICON_CATALOG_EN.md` — Markdown-каталоги, где GitHub сразу отображает 28 настоящих SVG. Локальная интерактивная версия HTML сохраняется.

Не удаляйте `dashboard.request` самостоятельно при штатной работе: приложение удаляет его после получения, UI-запрос никак не влияет на выключение.
