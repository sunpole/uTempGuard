Где редактировать исходники?

Исходные файлы: assets/logo/utg_w_*.svg и assets/logo/utg_b_*.svg. Изменяй их в CorelDRAW, сохраняй под прежним именем, затем отправляй изменения в GitHub. GitHub Actions заново создаст 64px кадры, которые uTempGuard покажет в трее. Эта страница отображает исходные SVG, а не переработанные PNG.
