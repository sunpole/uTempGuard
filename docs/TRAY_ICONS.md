# Температурные иконки uTempGuard: SVG → Windows Tray

## Исходники

Оригинальные SVG из CorelDRAW сохраняются без изменения в папке assets/logo/. Имя utg_w_* задаёт светлый значок для тёмной панели задач Windows, utg_b_* — тёмный значок для светлой панели задач. Цвет панели задач определяется параметром SystemUsesLightTheme (Windows), а не темой приложения.

После Git push исходных SVG в main GitHub Actions запускает .github/workflows/build-tray-icons.yml, устанавливает CairoSVG и Pillow и делает из каждого SVG ресурс assets/tray-icons/*.png.base64 размером 64×64 px. Исходники могут быть 900×900 и больше — масштабирование вектора идёт без потери исходника. Во время работы WinForms создаёт уменьшенный значок 32×32 px. Дополнительный SVG-движок на пользовательский Windows не устанавливается.

GitHub Actions делает отдельный коммит со сгенерированными кадрами. Если для main запрещён push GitHub Actions, сборка выдаст ошибку и монитор сохранит предыдущий статический логотип — никаких защитных функций это не затронет.

## Температурные диапазоны

| Температура подтверждённого источника отображения | Кадр |
| --- | --- |
| 0–9.99 °C | 000 |
| 10–19.99 °C | 010 |
| 20–29.99 °C | 020 |
| … | соответствующий нижний десяток |
| 70–79.99 °C | 070 |
| 80–89.99 °C | 080, 080_active |
| 90–99.99 °C | 090, 090_active |
| 100–110 °C | 100, 100_active |

Начиная с 80 °C, обычный кадр и active меняются каждые **0,4 секунды**, полный цикл занимает 0,8 секунды. При 70–79 °C анимация не нужна — это установленный пользователем визуальный стиль. Используется подтверждённая температура **из настройки «Показывать»**, независимо от выбора для аварийного выключения.

Если active-кадр отсутствует, используется обычный. Если нет, например, b_020, выбирается ближайший меньший доступный диапазон той же темы; далее другая тема. При недостоверном датчике, неизвестной температуре или отсутствии готовых картинок виден первоначальный **официальный статический логотип**, но не ложное значение 000. Неизвестный или повреждённый PNG никогда не останавливает защиту.

По представленному списку отсутствует utg_b_020.svg, но это не препятствует сборке. Фактические SVG пока присутствуют только на ПК пользователя и в GitHub ещё не опубликованы.

## Безопасность

Это ТОЛЬКО визуальная функция. Никаких изменений 70/75 °C, действий, Live, разрешений отключения и данных AIDA64. Картинка не означает, что аварийная защита вооружена. Когда выключение в Live разрешено при 75 °C, ПК может отключиться раньше, чем понадобятся кадры 80/90/100.

## Загрузка оригинальных файлов

В Git Bash в корне 015_uTempGuard:

    git status --short
    git add assets/logo/*.svg
    git commit -m "assets: add original CorelDRAW temperature icon SVGs"
    git pull --rebase origin main
    git push origin main

Загружаются только SVG и больше ничего. GitHub Actions создаст растрированные кадры вторым коммитом. Затем после успешного Workflow:

    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Manage.ps1 -Action Stop
    git pull --ff-only origin main
    powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./Manage.ps1 -Action Start

## Проверки

tests/Test-TrayIconSelector.ps1 проверяет диапазоны, светлую и тёмную темы, переключение каждые 0.4 секунды, неверные данные, неполные наборы. Проверки не включают аварийное выключение, не нагревают CPU и не запрашивают админ-права.
