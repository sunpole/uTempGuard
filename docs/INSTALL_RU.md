# Установка uTempGuard в Windows

[Главная страница](../README.md) · [English](INSTALL_EN.md) · [Руководство](USER_GUIDE_RU.md)

## Перед началом

- Windows 10/11 с Windows PowerShell 5.1 и поддержкой WinForms.
- Установленная **официальная AIDA64** с подписью FinalWire. Она поставляется и лицензируется отдельно, **не входит в ZIP**.
- Возможность включить экспорт AIDA64 в реестр: настройки AIDA64 → Мониторинг оборудования / External Applications → Registry (SensorValues). Названия пунктов могут различаться по версии. Должны появиться актуальные записи `TCPUPKG`, `TCC-1-1` … `TCC-1-14`, `SDATE`, `STIME`.
- Права обычного пользователя для запуска и автозапуска uTempGuard. AIDA64 может потребовать свои разрешения и настройку автозапуска отдельно.
- Не отключайте штатную аппаратную защиту BIOS/Windows. Это программный монитор, он не заменяет исправные кулеры.

## Простая установка из ZIP

1. Откройте [последний релиз](https://github.com/sunpole/uTempGuard/releases/latest). Выберите **прикреплённый** архив `uTempGuard-vX.Y.Z-win.zip`. Не путайте его с автоматически предлагаемым GitHub «Source code (zip)».
2. Извлеките архив в постоянную папку, например `C:\Tools\uTempGuard`. **Не запускайте прямо из архива**, не перемещайте папку после настройки автозапуска.
3. Двойным щелчком запустите `00_START-HERE.cmd`. При первом запуске откроется настройка `Setup-uTempGuard.ps1` (можно также открыть `Install-uTempGuard.cmd`).
4. Введите **полный путь к установленному `aida64.exe`**. Программа проверит наличие файла и цифровую подпись FinalWire. При отсутствии правильной подписи она откажется устанавливать.
5. Настройка создаёт локальный `config.json` **исключительно в режиме Observe**: показывать температуры, журналировать; **НЕ** выключать ПК и НЕ закрывать приложения.
6. Введите **INSTALL**, если согласны добавить автозапуск для текущего пользователя и сразу запустить монитор. Без INSTALL конфигурация создана, но автозапуск/запуск не выполняются.
7. Двойной щелчок по значку возле часов или по `Open-uTempGuard.cmd` открывает большое окно мониторинга. Правая кнопка открывает компактное меню. Закрытие большого окна не останавливает монитор. Проверьте значок у часов Windows, дайте AIDA64 обновить данные. При недостоверных датчиках uTempGuard сначала показывает отсутствие данных и блокирует автоматические действия.

## Уже есть рабочая uTempGuard

**Не запускайте первичную установку поверх действующей папки.** Сохраните текущие `config.json`, `live-approval.json`, папку `%LOCALAPPDATA%\uTempGuard` и репозиторий. Новый `Setup-uTempGuard.ps1` при наличии `config.json` ничего не перезаписывает.

Если у вас **Git-клон** со стандартным `origin=https://github.com/sunpole/uTempGuard`, обновление выполняется из приложения в разделе «Обновления» либо после проверки `git status --short`:

```powershell
.\Update-uTempGuard.ps1 -Action Preview
.\Update-uTempGuard.ps1 -Action Apply
.\Emergency-Control.ps1 -Action Status
```

Updater требует явного слова **UPDATE**, сохраняет локальные пользовательские файлы, блокирует изменения отслеживаемых файлов и конфликты путей. Он не включает Live или отключение автоматически.

## Обновление без потери данных

**Для ZIP-установки (без Git)**: сначала остановите работающий монитор через `Manage.ps1 -Action Stop`. Скачайте новый ZIP и **распакуйте его в новую отдельную папку**. Не перезаписывайте и не удаляйте старую папку. Скопируйте в новую папку свой `config.json` (отдельно и только после проверки), а при наличии `live-approval.json` **не считайте его автоматически действительным** — допуск связан с SHA-256 конфигурации и требует проверки. Переносить его без необходимости не следует. Настройки в `%LOCALAPPDATA%\uTempGuard` сохраняются отдельно, но автозапуск продолжит указывать на старый путь до переустановки ярлыка. Проверьте актуальный путь ярлыка и состояние Live перед запуском новой копии. Не запускайте обе копии одновременно.

**Для Git-клона**: не переносите файлы проекта, чтобы не сломать ярлык автозапуска. Встроенный Updater выполняет безопасное fast-forward и перезапуск. Локальные файлы проекта и CDR не удаляются.

## Как проверить работу

```powershell
.\Manage.ps1 -Action Status
.\Emergency-Control.ps1 -Action Status
.\Manage.ps1 -Action Diagnose
```

`ConfigurationMode=Observe` означает только наблюдение. Даже `Live` **не доказывает**, что выключение разрешено: отдельно проверяйте `ForcedShutdownArmed` и `ShutdownSourceApproved`. Не проверяйте пороги реальным нагревом ПК.

## Остановить, убрать автозапуск, удалить

```powershell
.\Manage.ps1 -Action Stop
.\Manage.ps1 -Action DisableStartup
```

`Uninstall.ps1` отключает ярлык текущего пользователя и пытается остановить монитор, **не удаляет** папку исходников, AIDA64, логи или локальную конфигурацию. Удалять файлы вручную не требуется.

## Типовые проблемы

- **Нет данных CPU**: проверьте запуск AIDA64, совпадение пути её exe, свежесть SensorValues и экспорт нужных каналов.
- **После входа Windows сначала ошибка**: AIDA64 могла запуститься позднее монитора. Дождитесь её работы; программа должна обновить показания самостоятельно. Не разрешайте действия при неподтверждённых датчиках.
- **Updater говорит «не Git-клон»**: вы установили ZIP. Пользуйтесь ручным обновлением или отдельным Git-клоном в постоянной папке.
- **Updater блокирует изменение**: выполните `git status --short`. Не используйте `reset --hard`, `clean -fd` или force push без независимой резервной копии.
- **Windows не может открыть .cmd/.ps1**: запускайте только файлы из официального репозитория; допускается запустить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Setup-uTempGuard.ps1` из распакованной папки. Не отключайте общесистемную политику PowerShell постоянно.

Для выбора датчиков и меню см. [руководство пользователя](USER_GUIDE_RU.md).
