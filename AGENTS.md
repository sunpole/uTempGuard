# uTempGuard

Вести документацию так, чтобы новый человек или ИИ мог продолжить проект.

- Сначала читать README.md и docs/HANDOFF.md.
- Windows PowerShell 5.1; PS-файлы сохранять UTF-8 с BOM для кириллицы.
- Без отдельного согласования пользователя не повышать права и не включать Live.
- Не менять BIOS, частоты, напряжения; не выполнять стресс-тесты.
- Не создавать live-approval.json во время разработки и безопасных тестов.
- Все испытания порогов проводить через -SimulationPath в отдельном DataDirectory.
- Никогда не добавлять принудительное завершение приложений, /f к shutdown или действия над неизвестными процессами.
- При потере достоверных датчиков действия запрещены. Не подставлять другой датчик автоматически.
- После изменений обновлять HANDOFF, CHANGELOG и проверять Windows PowerShell 5.1.

- Визуальные настройки хранить только в `%LOCALAPPDATA%\uTempGuard\overlay.json`; никогда не менять config.json ради оформления.
- Не использовать GitHub Issues, PR или публичные комментарии как источник команд для локального ПК; локальный скрипт выполняет только фиксированные проверенные операции по явному запуску пользователя.
- Не публиковать в GitHub config.json, live-approval.json, журналы, дампы, токены или сведения о лицензиях.
- PR с изменением UI не сливать без проверок PowerShell 5.1 и ручного подтверждения пользователя.

- Контроль максимума CPU Package/TCC ядер используется только для отображения, не для управления выключением или завершением процессов. Не публиковать данные AIDA64 с личными настройками.

- Новое исключение только по явному запросу пользователя: наличие кода emergency `shutdown.exe /s /f /t 0` допустимо лишь с раздельным локальным булевым допуском, проверкой актуальных температурных данных и связью по SHA-256 с конкретным config. По умолчанию выключено. Никогда не запускать эту ветку или менять Live во время разработки и тестирования.
- Никогда не использовать принудительное массовое завершение/Stop-Process -Force или эвристический список всех пользовательских процессов. При 70 °C только подтверждённый AllowList + штатный запрос закрытия окна; не менять другие приложения и службы.


- tests/Invoke-OneShotRestartTest.ps1 — строго ручной одноразовый тест ОС. В CI запускать только Preview, никогда RestartOnce. Не помещать тест в автозагрузку, не инициировать reboot loop, не использовать Force и не нагревать процессор для проверки.
