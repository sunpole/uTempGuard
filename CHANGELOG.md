# Изменения

## 0.1.1 — кандидат (25.10.2026)

- Вместо окна 350×76 px добавлен компактный индикатор CPU и полноразмерный режим.
- Настройки размера, фона, непрозрачности и положения через меню трея.
- Изолированное сохранение визуальных настроек в AppData; конфигурация датчиков и защиты не меняется.
- Безопасный PowerShell-апдейтер с Preview/Apply и запретом грязной/разошедшейся Git-копии.
- Добавлены изолированные тесты настроек; реальная проверка окна на Windows ещё требуется.

## 0.1.0 — 2026-10-25

- Создан Windows PowerShell5.1 монитор AIDA64 CPU Package с контролем heartbeat и ошибочных данных.
- Добавлены пороги70/75, гистерезис ниже69, нормализация CPU по всем логическим процессорам.
- Добавлены строго согласуемый allowlist и блокировка реальных действий в Observe/Simulation.
- Добавлены WinForms indicator/tray, JSONL журнал, status, диагностика, установка/удаление и current-user Startup.
- С отдельного разрешения зарегистрирована задача AIDA64 at user logon с повышением; монитор остаётся обычным процессом.
- Реальные закрытия/выключение и стресс-тесты не выполнялись. Live не активирован.

## Следующий кандидат — просмотр всех ядер CPU (отдельный PR)

- Только чтение: CPU Package и до 14 температурных каналов отдельных ядер при наличии экспорта AIDA64.
- В компактном индикаторе максимум среди корректных доступных значений; в трее список каналов.
- Проверка некорректных, повторных и отсутствующих значений; отсутствие автоматических действий по максимальной температуре.

## Кандидат: опциональная реакция на перегрев (не включена)

- При 70 °C опциональный режим ApprovedInteractive позволяет пытаться штатно закрывать только проверенные и предварительно разрешённые приложения.
- При 75 °C добавлен отдельный локальный допуск для принудительного завершения Windows с риском потери данных; по умолчанию выключен.
- Основной режим Observe и отсутствие Live-допуска сохраняются; без подписанного конфигурацией разрешения автоматических действий нет.
