## Кандидат: опциональная реакция на перегрев (не включена)

- При 70 °C опциональный режим ApprovedInteractive позволяет пытаться штатно закрывать только проверенные и предварительно разрешённые приложения.
- При 75 °C добавлен отдельный локальный допуск для принудительного завершения Windows с риском потери данных; по умолчанию выключен.
- Основной режим Observe и отсутствие Live-допуска сохраняются; без подписанного конфигурацией разрешения автоматических действий нет.

## Следующий патч — установка и явное аварийное разрешение

- Критическое решение выполняется до сканирования процессов: уменьшаем задержку реакции на 75 °C.
- Добавлен локальный Emergency-Control.ps1: Status/Enable/Disable, проверка 15 доступных датчиков, отдельный подтверждаемый аварийный допуск, резервная копия конфигурации, перезапуск.
- Ничего не включается автоматически через GitHub; риск потери данных при /f сохраняется.

## Исправление диагностики 15 CPU датчиков

- Добавлено определение причины ошибки вместо безмолвного `$null` по параметру `-Diagnostic`.
- Проверки целостности времени и температуры CPU Package не ослаблены; краткие гонки чтения реестра допускают ограниченные повторы.
- Режим включения аварийной защиты сообщает конкретные причины вместо общего сообщения.


## Одноразовая проверка перезагрузки

- Создан ручной тест: синтетические 75 °C, решение Critical/Shutdown, затем опциональный один штатный Restart-Computer без Force и без циклических повторов.
- Без изменения реального аварийного отключения и без физической тепловой нагрузки.
- Preview проверяется в Windows CI.


## Избавление от ложного стартового предупреждения

- Пока AIDA64 запускается после входа в Windows, uTempGuard подавляет только всплывающее окно начального SensorFault, максимум 45 секунд.
- Если источник не появился или пропал после первого успешного чтения, предупреждения остаются. Тепловые уведомления не затрагиваются; Live-разрешение, действия и показания не изменены.
- Новые изолированные тесты проверяют стартовую отсрочку, постоянную неисправность и повторную потерю датчика.


## Пять режимов температур: независимый индикатор и аварийное выключение

- Два меню: показывать температуру и источник 75 °C для выключения; каждое содержит Всё (AIDA64), ядра, ядра+CPU, ядра+CPU+Package, произвольные чекбоксы.
- Сохраняется исходный аварийный режим CPU Package + ядра при обновлении существующего Live; изменение только показаний экрана не перенастраивает защиту.
- Новый источник выключения требует ручного подтверждения, здоровых датчиков и отдельного допуска; старый допуск сразу отзывается, ничего не переключается «молча».
- Проверка всех выбранных каналов, свежести и повторное считывание перед действием; нет fallback при пропаже датчика.
- Поддержаны только подтверждённые AIDA64 температуры; Windows/WMI и неизвестные датчики не используются для силовых действий.
- Синтетические тесты проверяют пять режимов, повреждённый реестр/параметры, отдельную авторизацию источника и неизменность аварийного поведения при изменении экрана.


## v0.3.0 — официальный бренд и новое тёмное меню Windows

- Добавлен предоставленный пользователем официальный логотип SVG, его 64px WinForms/трей-вариант (base64), бренд-кнопки и ссылки для GitHub README.
- Вместо визуально устаревшего ContextMenuStrip по правому щелчку предлагается тёмная округлая панель uTempGuard: температура, CPU 15/15, пять режимов «Показывать что», пять режимов «Выключать ПК по температуре», галочки датчиков, подтверждение аварийного источника, внешний вид, GitHub/релизы/документация, остановка.
- Кнопки «Проверить обновления» и «Установить обновление» запускают существующий проверенный Updater в отдельном сеансе; установка требует ввода UPDATE и не производится автоматически.
- Сохраняются локальные настройки и разрешения. Пороги 70/75, производитель AIDA64 и защита не изменены; при сбое инициализации нового меню остаётся прежнее.
- Дополнительные CI-тесты Windows проверяют не только синтаксис, но и неотображаемое создание интерфейса и страниц меню; реальный UX требует проверки на ПК пользователя.


## v0.4.0 — плотное адаптивное меню и английский/русский интерфейс

- Реальные наблюдения на Windows 10 выявили длинные двухстрочные строки и меню, обрезающее нижние пункты. Теперь стандартная высота строк 26px вместо 45–68px; без переносов и с доступным полным названием для программ чтения с экрана.

- Добавлена docs/LOCALIZATION.md — формат JSON, правила переводов, автоматическое обнаружение новых валидных языков.
- Никаких изменений порогов 70/75°C, одобрений Live, выбора аварийного источника и функций отключения. Запрещённое выключение не включается при смене языка или интерфейса.
