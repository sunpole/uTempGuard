## Что это

**uTempGuard** — небольшая утилита для Windows, отображающая температурные данные из **AIDA64** в компактном индикаторе и значке возле часов. Она может предупреждать о нагреве и поддерживает отдельно подтверждаемые защитные действия. Это программный помощник, **не замена аппаратной термозащите или исправному охлаждению**.

Программа написана на Windows PowerShell 5.1 / WinForms, не требует Python, Node.js, сборщика или WebView2 на компьютере пользователя. **AIDA64 устанавливается и лицензируется отдельно**; в комплект не включена.

## Основные возможности

| Функция | Что делает |
|---|---|
| Температуры | Проверяет экспорт AIDA64, актуальность данных, CPU Package, ядра и другие доступные каналы |
| Два выбора источников | Отдельно настраиваются **что отображать** и **по каким датчикам оценивать отключение** |
| Температурные иконки | 28 оригинальных SVG, цветные варианты для светлой/тёмной панели задач, смена по десяткам градусов |
| Предупреждающие кадры | При 80°C и выше чередует normal/active через 0,4 с, если система продолжает работать |
| Современное меню | Тёмное компактное оформление, кнопка «Назад», стиль, размер, прозрачность, положение, язык |
| Локализация | Русский (основной) и English, расширяемые JSON-словари |
| Безопасность | По умолчанию **Observe**, никаких закрытий программ и выключения без отдельных допусков |
| Диагностика | Статус, локальный журнал и отдельные безопасные сценарии тестирования |

## Скачать и установить

1. Откройте [Releases](https://github.com/sunpole/uTempGuard/releases/latest) и скачайте прикреплённый **uTempGuard-vX.Y.Z-win.zip** (не перепутайте с автоматически созданным GitHub «Source code ZIP»).
2. Извлеките целиком в **постоянную папку**, например `C:\Tools\uTempGuard`. Не запускайте программу непосредственно из ZIP.
3. Запустите двойным щелчком **`00_START-HERE.cmd`** или **`Install-uTempGuard.cmd`**.
4. Укажите полный путь к **официальному подписанному aida64.exe**, включите экспорт температур AIDA64 (см. [инструкцию](docs/INSTALL_RU.md)).
5. По завершении откройте значок возле часов, проверьте показания. Новая установка работает **только в Observe**. Аварийное выключение никогда не включается установщиком.

**Важно для обновлений:** ZIP — ручная установка, без Git-истории. Кнопка обновления через Git предназначена для **клона репозитория**. При установке из ZIP скачивайте новую версию и следуйте [инструкции по обновлению](docs/INSTALL_RU.md#обновление-без-потери-данных). Не удаляйте рабочую папку и локальный `config.json`.

## Безопасность и ограничения

- Условия предупреждения и отключения в текущей конфигурации пользователя: **70°C / 75°C**. Эти пороги не универсальны для GPU, SSD и CPU; режим «Все датчики» для отключения требует особого внимания.
- Отключение может завершать Windows и несохранённые программы. Требуется отдельное подтверждение и свежие достоверные данные AIDA64. При зависании Windows или AIDA64 **нет гарантии своевременного срабатывания**.
- Нельзя считать отсутствие предупреждения или анимации подтверждением безопасности.
- `config.json`, `live-approval.json`, журналы и личные параметры **не входят в GitHub или ZIP**.
- Обновление не включает Live и не выдаёт себе новые разрешения.
